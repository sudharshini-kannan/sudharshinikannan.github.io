## 🧬 Introduction
RNA-Seq is widely used to analyze gene expression across biological conditions.
In this project, I performed a complete RNA-seq differential expression analysis using the DESeq2 package in R to compare **pregnancy vs lactation samples**.

---

## 📂 Dataset
- Dataset: **GSE60450**
- Source: NCBI GEO
- Organism: Mouse mammary gland RNA-seq

---

## ⚙️ Project Workflow

1. Download RNA-seq count data from GEO  
2. Prepare count matrix and metadata  
3. Perform differential expression using DESeq2  
4. Visualize results  

---
## 🧪 Data Preparation

- Extracted count matrix from GEO dataset  
- Removed unnecessary columns (gene length)  
- Created metadata with sample conditions

Example:
```python
conditions = ["pregnancy" if "-D" in s else "lactation" for s in samples]

## Differential Expression using DESeq2
dds <- DESeqDataSetFromMatrix(
  countData = counts,
  colData = metadata,
  design = ~ condition
)
dds <- DESeq(dds)
res <- results(dds)

```
